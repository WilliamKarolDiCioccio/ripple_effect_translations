# languages

One folder per language, named by its tag — `it`, `de`, `pt-BR`:

```
languages/pt-BR/
  app_pt_BR.arb    reviewed strings; what ships
  draft.arb        machine drafts; nobody has read them yet
  CONTRIBUTORS     who to credit, one per line
```

A folder is created when a language has a maintainer. See
[CONTRIBUTING.md](../CONTRIBUTING.md).
